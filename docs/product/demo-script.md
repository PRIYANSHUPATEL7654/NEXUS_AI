# Portfolio demo and screenshot script

Use a demonstration account containing synthetic data only. Never record real
documents, financial statements, email addresses, tokens or provider secrets.

## Suggested 4-6 minute demo

1. **Opening (20 seconds)** - explain that NEXUS is one privacy-first ecosystem,
   not five unrelated applications.
2. **Today (35 seconds)** - show the daily brief, recommendations, quick actions,
   Ask Nexus and notifications.
3. **Knowledge (45 seconds)** - upload a synthetic document, show review,
   summary generation and authenticated PDF export.
4. **Learn (45 seconds)** - choose a goal/topic by name, record progress and
   answer a locally generated quiz.
5. **Money (45 seconds)** - parse synthetic text, review/edit drafts, approve and
   show analytics. State that no bank permission is requested.
6. **Work (45 seconds)** - import a synthetic assignment, review task drafts and
   show the low/high project estimate.
7. **Intelligence (35 seconds)** - search across modules and explain audited,
   allow-listed tools.
8. **Engineering (40 seconds)** - show the architecture document, Alembic head,
   green GitHub Actions pipeline and Docker files.
9. **Mobile finish (30 seconds)** - show installed PWA and six-module bottom
   navigation.

## Screenshot checklist

Capture after production deployment and final QA:

1. Desktop Today dashboard with synthetic summaries.
2. Mobile Today screen with the six-module navigation dock.
3. Knowledge document and generated summary.
4. Learn goal/topic progress and quiz.
5. Money review drafts plus analytics, using synthetic amounts.
6. Work plan warnings/estimate and task list.
7. Unified search results and notification panel.
8. Green GitHub Actions `NEXUS CI` run.
9. Architecture diagram or repository README.

Crop browser/account details that are unrelated to the project. Recheck every
image for private names, email addresses, connection strings and uploaded file
contents before using it in a portfolio.

## One-sentence portfolio description

NEXUS AI is a Dockerized, CI-tested FastAPI and React PWA that unifies private
knowledge, learning, reviewed financial imports, work planning and explainable
cross-module intelligence with PostgreSQL ownership isolation.
